# 手書き絵 PNG変換ツール

ブラウザ上でjs-aruco2を使用してArUcoマーカーを検出し、手書きの絵を高解像度アルファPNGに変換するツールです。

## 機能

- 5x5 ArUcoマーカー（ID: 0-3）の検出
- パース補正（透視変換）による傾き・歪み補正
- 高解像度処理（4096x4096）
- 二値化とノイズ除去
- 自動バウンディングボックス検出と正方形クロップ
- アルファチャンネル付きPNG出力（黒=不透明、白=透明）
- A4印刷用テンプレート生成ツール付属

## 使い方

### 1. テンプレートの生成
1. ブラウザで `template-generator.html` を開く
2. 用紙サイズや描画枠サイズを調整（デフォルト: A4、150mm×150mm枠）
3. 「テンプレート生成」ボタンでプレビュー
4. 「PNGダウンロード（300dpi）」ボタンで印刷用画像を保存
5. 印刷して、枠内に絵を描く

### 2. 手書き絵のスキャンと変換
1. 描いた紙をスキャンまたは写真撮影
2. ブラウザで `index.html` を開く
3. スキャンした画像をアップロード
4. ArUcoマーカー（ID: 0-3）が自動検出され、パース補正が実行されます
5. 二値化閾値を調整（デフォルト: 225）
6. 「アルファ付きPNGをダウンロード」ボタンで保存

## 必要な環境

- モダンなWebブラウザ（Chrome, Firefox, Safari, Edgeなど）
- ローカルサーバー（ファイルプロトコルではなくHTTPプロトコルで実行する必要があります）

## セットアップ

```bash
# Pythonでローカルサーバーを起動
python3 -m http.server 8000

# または Node.jsの場合
npx http-server -p 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 重要な制限事項

**js-arucoライブラリの制限:**
- サポートされるマーカー: 5x5の内部データ領域を持つArUcoマーカーのみ
- サポートされるID: 0, 1, 2, 3 の4種類のみ
- マーカー形式: 7x7マス（外枠1 + データ5x5 + 外枠1）

## マーカーの配置

画像内に以下のIDのArUcoマーカーを配置してください：
- ID 0: 左上
- ID 1: 右上
- ID 2: 右下
- ID 3: 左下

※実際の位置は自動的に判定されますが、4つのマーカーが必要です。
※テストマーカー生成ツール（`test-marker-generator.html`）を使用すると簡単に作成できます。

## 技術スタック

- js-aruco2 (JavaScript ArUco marker detector)
- HTML5 Canvas
- 透視変換（ホモグラフィ変換）
- 連結成分ラベリング（ノイズ除去）

## ファイル構成

- `index.html` - メイン処理画面
- `handwriting-processor.js` - ArUco検出、パース補正、二値化、PNG生成のロジック
- `template-generator.html` - テンプレート生成ツール
- `cv.js`, `aruco2.js` - js-aruco2ライブラリ

## パラメータ調整

### 切り取り余白（デフォルト: 3.5mm）
- ARマーカーから描画エリアまでの内側余白
- マーカーが描画に含まれないように調整

### 二値化閾値（デフォルト: 225）
- 0-255の範囲で調整可能
- 高い値 = より暗い部分のみ黒として認識
- 低い値 = 薄い線も黒として認識

### 白黒反転
- 背景が黒で絵が白い場合にチェック

## 出力仕様

- 解像度: 最大4096x4096px
- 形式: PNG（アルファチャンネル付き）
- バウンディングボックス: 正方形、5mm余白付き
- ノイズ除去: 約0.5mm×0.5mm以下の黒点を自動削除
